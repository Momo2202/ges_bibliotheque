# Gestion de bibliothèque

API REST de gestion d'une bibliothèque développée avec Django REST Framework,
MySQL et Docker Compose.

## Prérequis

- Docker Desktop
- Docker Compose
- Git

## Architecture métier

- Authors
- Categories
- Books
- Members
- Loans

## Démarrage

La procédure complète de démarrage sera documentée après la création
du projet Django et la validation de la connexion à MySQL.

## Sécurité

Le fichier `.env` contient les paramètres locaux et ne doit pas être
publié dans le dépôt Git.
